# Contrato de restablecimiento

## Estado

**Implementado para la versión 1.0.**

## Propósito

El restablecimiento completo elimina el estado construido entre un usuario y un personaje y crea una relación nueva basada únicamente en la configuración base.

El reset no elimina la cuenta del usuario ni modifica el personaje base.
